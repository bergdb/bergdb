This package implements low-level append-only byte streams. Package was created in 2008.

Depends on: common.

Append-only stream

The AppendOnlyStream interface is the most important interface of this package. It provides a low-level, write once stream interface for the rest of the system to use. Implementations in this package include both in-memory and on disk implementations.

Note that the append-only stream do not require any knowledge of the bytes of the stream, it just provides random read access and append access to a stream of bytes.

The classes in this package are not thread-safe unless otherwise documented.
