This is the full Javadoc of all KissDB classes, focus on using the smaller Pub API (package kissdb.pub) if that is enough for you.

KissDB developers (those who wish to modify the KissDB library) should start by reading the docs for package kissdb.dev.

The API formed by all classes of KissDB is certainly *not* expected to be stable between KissDB versions and releases. Stick to using the Pub API for better compatibility with future releases.

With that said, there are useful features that are not available from Pub and for highest possible performance, use the class kissdb.core.Db directly. The test source code in DbTester, for example, could be of interest if you like to know how to use Db directly.

The class pubimp.DbObject can also be of interest - this class is used to serialize Java object for storage.
