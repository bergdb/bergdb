029-going-public
================

Created 2026-11-16 by Frans Lundberg. Status: done.

Making BergDB's repository public. This item records the changes made in
this repository for the public release, so that a reader of the history
can follow them.


Outcome
=======

BergDB's repository has been public since 2026-11-17, 14:18:

* the repository: https://github.com/bergdb/bergdb, under the Apache
  License 2.0 (`LICENSE`, `NOTICE`), releases 2026.1 to 2026.5 included;
* the releases page: https://github.com/bergdb/bergdb/releases, with
  each release's jar and `SHA256SUMS`; `releases/` keeps each release's
  readme and `SHA256SUMS`;
* the site: https://bergdb.org.

The public repository is a new one, made from the private one with its
history kept from 2013: the commits of 2013 to 2017 come first, then
those of 2026. The history was cleaned, so every commit hash changed:

* private material was removed from every version: private notes,
  personal details and contact data, and old login names; every
  author, committer and tagger is frans.lundberg@gmail.com;
* the release binaries were dropped from every version; they are on the
  releases page;
* `Co-Authored-By` lines were removed from the commit messages;
* `LICENSE` reads the Apache License 2.0 in every version of the 2026
  history;
* the commit hashes cited in the files and the commit messages were
  mapped to the new hashes. A hash of before 2026-11-17 cited outside
  this repository does not resolve here.

The commits of 2026-11-17 marked `029:` made the current files ready:
README.md for users, CONTRIBUTING.md, SECURITY.md, the licence, the
release notes, and no private data in the current files. The former
private repository is archived, read only.
