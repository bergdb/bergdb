/-
The PE trial (bergdb 026-24; the design in 026-23, section 1.2): PE's writer
(Pe/Plan.lean) and today's writer (lean/SIS/Tree/Exec.lean, unchanged) run on
the operations of Java's traces (027-02, format 3) and on 026-21's workloads,
in the model, each from the empty tree on its own structure P. Adapted from
026-21's `steptimes` (lean/study/StepTimes.lean on the branch 026-21-study):
the same checks, counts and stand-in bytes; one step a transaction.

Usage: petrial MODE [--contract] [--paired] [--pec] [--pecrun] [--hplus=K] TRACE...

Modes:
  today  today's writer (`putKv` for each operation), a transaction at time T.
  pe     PE's writer (`Pe.runTx`), a transaction at time T. In every
         transaction of one operation, today's writer is run beside it from
         the same P, and the two changes are compared (`cmp1`, below).
  peh    as pe, with a list longer than h cut into parts of at most M / 2
         entries, not h (`Pe.Opt.cap`; 026-24, section 2.6): the fill.
  pet    as pe, with a base full by size cut as today's rule O cuts it
         (`Pe.Opt.todayCut`; 026-24, section 1, F1 and F2) in transactions of
         one operation: for cmp1 only, to show that the differences of one
         operation are F1 to F3.
  With --paired (mode pe), today's writer is run from PE's P for every
  transaction, and the bytes of its changes are summed too (`p*` counts):
  a comparison with the same tree before each transaction.

The checks, each failure counted by name (as 026-21's):
  map       after each transaction, the get of each of its keys against the
            reference (the program's map of the operations); each GET and
            SCAN line of Java's trace; every 10th transaction and the last, a
            full forward scan; at the run's end a full scan at every 50th
            transaction against the reference of then.
  contract  (with --contract) at every transaction, the contract of
            lean/contract: `contractOk` (C1, the invariants; C2, the contents
            with the operations), the frame (C3: `extOk` and D, over the nodes
            the transaction changed, as no other node of P changes), TREE (C4,
            `treeOkB`), the top (C5, `topStepB` and the roots' link). The
            writer's own rules (`shapeFaults`: the fill, the leftmost rule,
            two live klongs in an inner root, theta, the heights) are counted
            by name (`shapeend`): for PE each is a fault of the trial.
  cmp1      (mode pe) a transaction of one operation: today's changes and
            PE's, from the same P, compared on the tree they give at T: the
            key nodes reached that are new or got entries at T, new ids
            renamed in the order of a walk. `exact`: the same entries;
            `lists`: not the same entries, but the same live lists (the
            layout of klongs differs); `other`: the lists differ. Each
            `other` is printed (CMP1 lines, at most 20 a trace).
  made      every key node made is named by a live klong of a key node the
            transaction changed or made, or is the new space root
            (`made.unnamed`): no node made is left out.
  error     an error of the writer (`Bug:`, `corrupt:`, `bounds:`): the trace
            stops there.

The new writer (bergdb 030-21; lean/contract/Contract/PeWriter.lean,
`Contract.PE.peTx`, total functions on the contract's tree), with the Cfg
of the trial's Params (after --hplus): M, G, H, m = mergeBelow, c =
mergeMax, h = splitAbove, theta, cap = splitAbove (mode pe):
  --pec     (mode pe; turns --contract on) at every transaction, peTx is run
            on the trial's contract heap of the tree before, its top, at
            time T, with the trial's next id before the transaction and the
            transaction's operations; its tree after (`Out.tree`, here as a
            hash map: `applyOut`) is compared with the trial's (the heap after
            `checkContract`): both walked from their space roots at T in
            parallel, ids matched (an old id, below the trial's next id, only
            with itself; a new id of one one to one with a new id of the
            other); each pair of nodes reached: a value's hash; a key node's
            level, leaf flag and all its klongs (time klongs equal, bitmaps
            as sets, key klongs with equal compare values and matched ids);
            the space roots (old ones equal, a new one matched) and the top
            (each top node: id matched, root time, root pointer matched, skip
            pointers). Counts `same`, `differ` (the first ones printed,
            PECDIFF lines), `refused` (peTx gave none; by reason, `refusedby`:
            `longdel`, every key of more than G + 1 segments is a delete's,
            a noop, which the trial and Java do as nothing; `longput`;
            `other`) and `wsdup` (a node written twice), one line `PEC ...` a
            trace after RESULT. A transaction refused for `longdel` is run
            again without those deletes and compared too (`fsame`,
            `fdiffer`, `frefused`). PETRIAL FAILED if any differ, refused or
            wsdup. RESULT is unchanged.
  --pecdump=T  (with --pec) the tree before the transaction at T and the
            nodes each writer made or appended to, printed (a debugging aid).
  --pecrun  the new writer alone, from PeWriter's `startTree`, `startTop` and
            `startNext` (checked to be the trial's primordial structure as
            runTrace builds its heap and top; else the trial's, said in the
            PECSTART line), on its own state through the whole trace. At every
            transaction, each failure counted by name: `C1.inv`,
            `C2.contents` (`contractOk`), `C3.frame` (as checkContract
            computes it, over the nodes written, and the roots extended),
            `ids.fresh` (a new node's or top node's id at or above the next
            id), `C4.tree` (`treeOkB` at T), `C5.top` (`topStepB` and the
            roots' link), `shape.*` (`shapeFaults`), `C2.reference` (the
            contents at T against the reference map), `map.get` (each key of
            the transaction, the contract's `get`), `map.javaget` and
            `map.javascan` (Java's GET and SCAN lines, the contract's `get`
            and `scan` at their times), `wsdup`; at the end `map.history`
            (the contents at every 50th transaction against the reference of
            then). A refusal is counted by reason (as --pec's); one for
            `longdel` is run again without those deletes and the run goes on,
            any other stops the trace. Prints one line `PECRUN ...` a trace,
            with the stand-in counts of RESULT that depend only on the trees
            (madekey, versions, tops, bnew, ball, btop); PETRIAL FAILED if a
            failure or a refusal.

Prints one line `RESULT key=value ...` a trace, then PETRIAL OK or PETRIAL
FAILED.
-/

abbrev Nodes := Std.HashMap NodeId (Node BVal)

def keyCmp (a b : Key) : Ordering := if keyLt a b then .lt else if a == b then .eq else .gt

abbrev Ref := Std.TreeMap Key Nat keyCmp

def viewN (P : Nodes) : View BVal := fun x => P[x]?

def toNodes (P : Struct BVal) : Nodes := P.foldl (fun m q => m.insert q.1 q.2) {}

/-- `Struct.apply` on the hash map (as 026-17's `applyC`). -/
def applyC (P : Nodes) (i : Time) (c : Changes BVal) : Except String Nodes := do
  let mut P := P
  for n in c.new do
    if P.contains n.id then throw s!"IdsFresh: node {n.id}, made at {i}, exists"
    P := P.insert n.id { level := n.level, isData := n.isData, hist := [] }
  for (x, v) in c.adds do
    match P[x]? with
    | some nd => P := P.insert x { nd with hist := nd.hist ++ [⟨i, v⟩] }
    | none => throw s!"PointersOK: an entry at {i} for node {x}, no node of P"
  for (_, v) in c.adds do
    for y in bptrs v do
      if !P.contains y then throw s!"PointersOK: an entry at {i} names {y}, no node of P"
  return P

inductive Mode where
  | today | pe | pet | peh
  deriving BEq, Repr, Inhabited

def Mode.name : Mode → String
  | .today => "today" | .pe => "pe" | .pet => "pet" | .peh => "peh"

def Mode.ofString : String → Option Mode
  | "today" => some .today | "pe" => some .pe | "pet" => some .pet | "peh" => some .peh
  | _ => none

/-! ## The contract's view of P -/

def kOf : Klong → Contract.Klong
  | .time t => .time t
  | .key c y => .key c y
  | .del b => .del b

def opOf : Tree.Op → Contract.Op
  | .put k h => .put k h
  | .del k => .del k

def objOf (p : Params) (nd : Node BVal) : Option Contract.Obj :=
  if nd.isData then
    match nd.hist.findSome? (fun e => match e.val with
      | .data h => some h
      | _ => none) with
    | some h => some (.val h)
    | none => none
  else if p.keyMax < nd.level then none
  else some (.key { level := nd.level, leaf := p.heightOf nd.level == 0,
                    ks := (klongsOf nd.hist).map kOf })

structure Cfg where

structure St where
  P : Nodes
  next : NodeId := 1000
  ref : Ref := ∅
  snaps : Array (Nat × Ref) := #[]
  heap : Contract.Heap := {}
  tp : Contract.Top := []
  stats : Stats := {}

def startW (p : Params) (P : Nodes) (next : NodeId) : Except String W := do
  let v := viewN P
  match lastTop v with
  | none => throw "corrupt: the root has no top node"
  | some z =>
    let top ← topOf p (rootless v) z
    pure { next := next, top := top }

def runAct {α : Type} (p : Params) (P : Nodes) (s : Time) (w : W) (a : M α) :
    Except String (α × W) :=
  (a.run { p := p, i := s, view := rootless (viewN P) }).run w

def keyNodeBytes (nd : Node BVal) : Nat := 32 + 16 * (klongsOf nd.hist).length

def topNodeOf (s : Time) (t : SIS.Tree.Top) (tp : Contract.Top) : Contract.TopNode :=
  ⟨s, t.rootKey, t.skips.map (fun q => (q.1, q.2, ((tp.node q.2).map (·.time)).getD 0))⟩

/-- The contract at the transaction's end (026-21's `checkContract`, one step a
transaction). -/
def checkContract (cfg : Cfg) (st : St) (s : Time) (ops : List Tree.Op) (c : Changes BVal) (w : W) :
    St := Id.run do
  let p := cfg.p
  let mut stt := { st.stats with cSteps := st.stats.cSteps + 1 }
  let D : Std.HashSet NodeId := Std.HashSet.ofList (w.nodes.map (·.1) ++ w.made.map (·.id))
  let ids : Std.HashSet NodeId := Std.HashSet.ofList (c.new.map (·.id) ++ c.adds.map (·.1))
  let mut objs := st.heap.objs
  let mut frameOk := true
  for x in ids.toList do
    match st.P[x]? with
    | none => pure ()
    | some nd =>
      match objOf p nd with
      | none => pure ()
      | some o' =>
        match objs[x]? with
        | some o =>
          if !(Contract.extOk s o o' && (D.contains x || o' == o)) then frameOk := false
        | none =>
          match o' with
          | .key _ => if !D.contains x then frameOk := false
          | .val _ => pure ()
        objs := objs.insert x o'
  let mut roots := st.heap.roots
  let mut tp := st.tp
  if w.newTop then
    roots := roots ++ [(s, w.top.rootKey)]
    tp := tp ++ [(w.top.id, topNodeOf s w.top st.tp)]
  let h' : Contract.Heap := { objs := objs, roots := roots }
  let cp : Contract.Params := { M := p.M }
  let cops := ops.map opOf
  if !frameOk then stt := stt.fail "C3.frame" s!"T {s}"
  if !Contract.contractOk cp s h'.tree cops h'.tree then
    if !Contract.invOk cp (h'.tree.at s) then stt := stt.fail "C1.inv" s!"T {s}"
    else stt := stt.fail "C2.contents" s!"T {s}"
  if !Contract.treeOkB (h'.tree.at s) then stt := stt.fail "C4.tree" s!"T {s}"
  if !(Contract.topStepB s st.tp tp && h'.roots == Contract.rootsOf tp) then
    stt := stt.fail "C5.top" s!"T {s}"
  let q : Contract.ShapeParams := ⟨p.H, p.mergeBelow, p.theta⟩
  for f in (Contract.shapeFaults q (h'.tree.at s)).eraseDups do
    stt := { stt with shapeEnd := bump stt.shapeEnd f }
    if cfg.mode != .today then stt := stt.fail s!"shape.{f}" s!"T {s}"
  return { st with heap := h', tp := tp, stats := stt }

/-! ## 030-21: the new writer (Contract/PeWriter.lean) beside the trial's, `--pec` -/

/-- The new writer's parameters from the trial's (mode pe: the cut's cap is h). -/
def peCfg (p : Params) : Contract.PE.Cfg :=
  { M := p.M, G := p.G, H := p.H, m := p.mergeBelow, c := p.mergeMax, h := p.splitAbove,
    theta := p.theta, cap := p.splitAbove }

/-- The heap after the writes of o: `Out.tree` as a hash map. `applyWs` takes
the first write of a node in ws (the latest); folding ws from its end, the
latest write is inserted last, so the two agree on every id. -/
def applyOut (h : Contract.Heap) (o : Contract.PE.Out) : Contract.Heap :=
  { objs := o.ws.reverse.foldl (fun m (x, ob) => m.insert x ob) h.objs, roots := o.roots }

/-- The ids that ws writes more than once. -/
def wsDups (ws : List (NodeId × Contract.Obj)) : Nat :=
  (ws.foldl (fun (acc : Std.HashSet NodeId × Nat) (x, _) =>
    if acc.1.contains x then (acc.1, acc.2 + 1) else (acc.1.insert x, acc.2)) ({}, 0)).2

def showK : Contract.Klong → String
  | .time t => s!"t{t}"
  | .key c y => s!"k{c}>{y}"
  | .del b => s!"d{b}"

def showKs (ks : List Contract.Klong) : String := " ".intercalate (ks.map showK)

/-- The parallel walk's state: the matching of new ids (trial to new writer
and back), the trial's nodes walked, the differences. -/
structure Match where
  fwd : Std.HashMap NodeId NodeId := {}
  bwd : Std.HashMap NodeId NodeId := {}
  seen : Std.HashSet NodeId := {}
  nodes : Nat := 0
  ndiff : Nat := 0
  diffs : Array String := #[]

def Match.diff (mt : Match) (s : String) : Match :=
  { mt with ndiff := mt.ndiff + 1, diffs := if mt.diffs.size < 3 then mt.diffs.push s else mt.diffs }

/-- Id a of the trial's tree and id b of the new writer's paired: an old id
(below the next id before the transaction) only with itself; a new id one to
one with a new id. -/
def Match.pair (next : NodeId) (mt : Match) (a b : NodeId) : Match × Bool :=
  if a < next || b < next then (mt, a == b)
  else match mt.fwd[a]?, mt.bwd[b]? with
    | none, none => ({ mt with fwd := mt.fwd.insert a b, bwd := mt.bwd.insert b a }, true)
    | some b', some a' => (mt, b' == b && a' == a)
    | _, _ => (mt, false)

/-- Two bitmaps as sets. -/
def sameBits (x y : List Nat) : Bool := x.all y.contains && y.all x.contains

def klongPair (next : NodeId) (mt : Match) : Contract.Klong → Contract.Klong → Match × Bool
  | .time t, .time t' => (mt, t == t')
  | .del x, .del y => (mt, sameBits x y)
  | .key c y, .key c' y' => if c == c' then mt.pair next y y' else (mt, false)
  | _, _ => (mt, false)

def klongsPair (next : NodeId) (mt : Match) : List Contract.Klong → List Contract.Klong → Match × Bool
  | [], [] => (mt, true)
  | a :: r, b :: r' =>
    let (mt, ok) := klongPair next mt a b
    if ok then klongsPair next mt r r' else (mt, false)
  | _, _ => (mt, false)

/-- The parallel walk from node a of the trial's tree ta and node b of the new
writer's tb (both at T): the pair compared, then the live children in pairs. -/
partial def walkPair (next : NodeId) (ta tb : Contract.Tree) (mt : Match) (a b : NodeId) : Match :=
  if mt.seen.contains a then mt else
  let mt := { mt with seen := mt.seen.insert a, nodes := mt.nodes + 1 }
  match ta.obj a, tb.obj b with
  | some (.val h), some (.val h') =>
    if h == h' then mt else mt.diff s!"value {a}/{b}: hash {h} / {h'}"
  | some (.key n), some (.key n') =>
    if n.level != n'.level || n.leaf != n'.leaf then
      mt.diff s!"key node {a}/{b}: level {n.level}/{n'.level}, leaf {n.leaf}/{n'.leaf}"
    else
      let (mt, ok) := klongsPair next mt n.ks n'.ks
      if !ok then mt.diff s!"key node {a}/{b} level {n.level}: trial [{showKs n.ks}] / new [{showKs n'.ks}]"
      else
        let la := Contract.live n.ks
        let lb := Contract.live n'.ks
        if la.length != lb.length then mt.diff s!"key node {a}/{b}: live {la.length}/{lb.length}"
        else (la.zip lb).foldl (fun mt (ea, eb) => walkPair next ta tb mt ea.2 eb.2) mt
  | none, none => mt.diff s!"node {a}/{b}: in neither tree"
  | _, _ => mt.diff s!"node {a}/{b}: of other kinds"

/-- The space roots after: the same times, the ids paired. -/
def rootsPair (next : NodeId) (mt : Match) : List (Time × NodeId) → List (Time × NodeId) → Match
  | [], [] => mt
  | (t, x) :: r, (t', y) :: r' =>
    let (mt, ok) := mt.pair next x y
    let mt := if ok && t == t' then mt else mt.diff s!"space root ({t}, {x}) / ({t'}, {y})"
    rootsPair next mt r r'
  | ra, rb => mt.diff s!"space roots: {ra.length} more / {rb.length} more"

/-- The tops after: each top node's id paired, its root time, its root pointer
paired, its skip pointers (index, target paired, cached time). -/
def topsPair (next : NodeId) (mt : Match) : Contract.Top → Contract.Top → Match
  | [], [] => mt
  | (za, na) :: r, (zb, nb) :: r' =>
    let (mt, ok1) := mt.pair next za zb
    let (mt, ok2) := mt.pair next na.root nb.root
    let (mt, ok3) := if na.skips.length != nb.skips.length then (mt, false) else
      (na.skips.zip nb.skips).foldl (fun (acc : Match × Bool) (qa, qb) =>
        if !acc.2 then acc else
          let (m, ok) := acc.1.pair next qa.2.1 qb.2.1
          (m, ok && qa.1 == qb.1 && qa.2.2 == qb.2.2)) (mt, true)
    let mt := if ok1 && ok2 && ok3 && na.time == nb.time then mt else
      mt.diff s!"top node {za}/{zb}: {repr na} / {repr nb}"
    topsPair next mt r r'
  | ta, tb => mt.diff s!"top: {ta.length} more / {tb.length} more"

/-- The key nodes of tree s from x, indented by depth: every one, or (onlyNew)
those that are not as in s0. -/
partial def dumpWalk (s s0 : Contract.Tree) (onlyNew : Bool) (depth : Nat) (acc : Array String)
    (x : NodeId) : Array String :=
  match s.obj x with
  | some (.key n) =>
    let acc := if onlyNew && s0.obj x == s.obj x then acc else
      acc.push (String.ofList (List.replicate (2 * depth) ' ') ++
        s!"{x} L{n.level}{if n.leaf then " leaf" else ""} [{showKs n.ks}]" ++
        (if s0.obj x == none then " NEW" else if s0.obj x != s.obj x then " APPENDED" else ""))
    (Contract.live n.ks).foldl (fun acc (_, y) => dumpWalk s s0 onlyNew (depth + 1) acc y) acc
  | _ => acc

def dumpTx (name : String) (T : Nat) (ops : List Tree.Op) (s0 ta tb : Contract.Tree) : Array String :=
  let hd := #[s!"PECDUMP {name} T={T}: {ops.length} operations"] ++
    (ops.map (fun op => match op with
      | .put k h => s!"  put {k} {h}"
      | .del k => s!"  del {k}")).toArray
  let r0 := (s0.at (T - 1)).root.getD 0
  let a := dumpWalk s0 s0 false 1 #["the tree before:"] r0
  let b := dumpWalk ta s0 true 1 #["the trial's nodes new or appended:"] (ta.root.getD 0)
  let c := dumpWalk tb s0 true 1 #["the new writer's nodes new or appended:"] (tb.root.getD 0)
  hd ++ a ++ b ++ c

/-- Why peTx refused operations ops (the first test of `peTx`, `opsOk`): a key
of more than G + 1 segments, all such ones deletes (`longdel`; such a key can
be in no tree within the level bounds, so the delete is a noop, which the
trial's writer and Java do as nothing); a put of such a key (`longput`); or
another reason (`other`: a key not well formed, or the tree). -/
def refusalOf (cf : Contract.PE.Cfg) (cops : List Contract.Op) : String :=
  let long := cops.filter (fun op => decide (cf.G + 1 < op.key.length))
  if long.isEmpty then "other"
  else if long.all (fun op => match op with
    | .del _ => true
    | .put _ _ => false) then "longdel"
  else "longput"

/-- The operations without the keys of more than G + 1 segments. -/
def dropLong (cf : Contract.PE.Cfg) (cops : List Contract.Op) : List Contract.Op :=
  cops.filter (fun op => decide (op.key.length ≤ cf.G + 1))

/-- The new writer's tree after (from its out o) against the trial's (st):
the parallel walk from the space roots at T, and the tops. -/
def pecCompare (st0 st : St) (T : Nat) (o : Contract.PE.Out) : Match × Contract.Tree × Contract.Tree :=
  let next := st0.next
  let hb := applyOut st0.heap o
  let ta := st.heap.tree.at T
  let tb := hb.tree.at T
  let mt : Match := rootsPair next {} st.heap.roots o.roots
  let mt := match ta.root, tb.root with
    | some ra, some rb =>
      let (mt', ok) := mt.pair next ra rb
      if ok then walkPair next ta tb mt' ra rb else mt'.diff s!"space root at T {ra}/{rb}"
    | _, _ => mt.diff "no space root at T"
  (topsPair next mt st.tp o.top, ta, tb)

/-- The check of `--pec` at the transaction at time T: the new writer from the
trial's heap, top and next id before it (st0), its tree after compared with
the trial's (st, after `checkContract`). A refusal for `longdel` is run again
without those deletes, and that tree compared too (the `f*` counts). -/
def pecCheck (cfg : Cfg) (name : String) (st0 st : St) (T : Nat) (ops : List Tree.Op) : St := Id.run do
  let mut stt := st.stats
  let cf := peCfg cfg.p
  let cops := ops.map opOf
  let mut out := Contract.PE.peTx cf T st0.heap.tree st0.tp st0.next cops
  let mut filtered := false
  if out.isNone then
    let why := refusalOf cf cops
    stt := { stt with pecRefused := stt.pecRefused + 1, pecRefusedBy := bump stt.pecRefusedBy why }
    if stt.pecLines.size < 6 then
      let line := s!"PECREFUSED {name} T={T} ops={ops.length} {why}: {(ops.take 3).map opStr0}"
      stt := { stt with pecLines := stt.pecLines.push line }
    if why == "longdel" then
      filtered := true
      out := Contract.PE.peTx cf T st0.heap.tree st0.tp st0.next (dropLong cf cops)
      if out.isNone then stt := { stt with pecFRefused := stt.pecFRefused + 1 }
  match out with
  | none => pure ()
  | some o =>
    let (mt, ta, tb) := pecCompare st0 st T o
    if cfg.dump == some T then
      stt := { stt with pecLines := stt.pecLines ++ dumpTx name T ops st0.heap.tree ta tb }
    let dups := wsDups o.ws
    stt := { stt with pecNodes := stt.pecNodes + mt.nodes, pecWsDup := stt.pecWsDup + dups }
    if mt.ndiff == 0 then
      stt := if filtered then { stt with pecFSame := stt.pecFSame + 1 }
        else { stt with pecSame := stt.pecSame + 1 }
    else
      stt := if filtered then { stt with pecFDiffer := stt.pecFDiffer + 1 }
        else { stt with pecDiffer := stt.pecDiffer + 1 }
      if stt.pecLines.size < 6 then
        let ds := mt.diffs.toList.map (fun d => s!"\n  {d}")
        let line := s!"PECDIFF {name} T={T} ops={ops.length} {(ops.take 3).map opStr0} " ++
          s!"differences={mt.ndiff}{if filtered then " (longdel left out)" else ""}" ++ String.join ds
        stt := { stt with pecLines := stt.pecLines.push line }
  return { st with stats := stt }
where
  opStr0 : Tree.Op → String
    | .put k _ => s!"put {k}"
    | .del k => s!"del {k}"

/-- The bytes of a transaction's changes c on P (026-17's stand-ins, as
026-21's): the record (48 + 16 a changed key node), the top nodes (48 + 16 a
skip pointer), the key nodes made (B-new) and every key node changed (B-all),
each whole at the transaction's end; and the counts of key nodes made and key
klongs added. -/
structure Bytes where
  recB : Nat := 0
  top : Nat := 0
  new : Nat := 0
  all : Nat := 0
  madeKey : Nat := 0
  tops : Nat := 0
  klongs : Nat := 0
  changed : Std.HashSet NodeId := {}
  made : List NodeId := []

def bytesOf (p : Params) (P' : Nodes) (c : Changes BVal) : Bytes := Id.run do
  let isKey (x : NodeId) : Bool := match P'[x]? with
    | some nd => !nd.isData && decide (nd.level ≤ p.keyMax)
    | none => false
  let madeKeys := (c.new.filter (fun n => !n.isData && decide (n.level ≤ p.keyMax))).map (·.id)
  let tops := c.new.filter (fun n =>
    !n.isData && decide (p.topLevel 0 ≤ n.level) && decide (n.level < p.rootLevel))
  let keyAdds := c.adds.filter (fun q => isKey q.1)
  let changed : Std.HashSet NodeId := Std.HashSet.ofList (madeKeys ++ keyAdds.map (·.1))
  let topB := tops.foldl (fun b z => b + 48 + 16 * (match P'[z.id]? with
    | some nd => nd.hist.countP (fun e => match e.val with
      | .skip _ _ => true
      | _ => false)
    | none => 0)) 0
  let size (y : NodeId) : Nat := match P'[y]? with
    | some nd => keyNodeBytes nd
    | none => 0
  return { recB := 48 + 16 * changed.size, top := topB,
           new := madeKeys.foldl (fun a y => a + size y) 0,
           all := changed.fold (fun a y => a + size y) 0,
           madeKey := madeKeys.length, tops := tops.length, klongs := keyAdds.length,
           changed := changed, made := madeKeys }

/-! ## The comparison of one operation (cmp1) -/

structure Canon where
  names : Std.HashMap NodeId String := {}
  k : Nat := 0
  exact : Array String := #[]
  lists : Array String := #[]
  newKeys : Nat := 0
  oldChanged : Array NodeId := #[]

def showVal (nm : NodeId → String) : BVal → String
  | .key c y => s!"k{c}>{nm y}"
  | .del cs => s!"d{cs}"
  | v => s!"{repr v}"

def Canon.name (cn : Canon) (P0 : Nodes) (y : NodeId) : Canon × String :=
  if P0.contains y then (cn, s!"o{y}") else
    match cn.names[y]? with
    | some s => (cn, s)
    | none =>
      let s := s!"n{cn.k}"
      ({ cn with names := cn.names.insert y s, k := cn.k + 1 }, s)

/-- The canonical form of the tree P at time t (the latest), against P0 (the
tree before): see the header, cmp1. -/
partial def canonWalk (p : Params) (P0 P : Nodes) (t : Time) (cn : Canon) (x : NodeId) : Canon := Id.run do
  match P[x]? with
  | none => return cn
  | some nd =>
    if nd.isData || p.keyMax < nd.level then return cn
    let kn : KNode := { leaf := p.heightOf nd.level == 0, ks := klongsOf nd.hist }
    let lv := kn.live
    let mut cn := cn
    -- name the children in order
    for (_, y) in lv do
      cn := (cn.name P0 y).1
    let nm (y : NodeId) : String := if P0.contains y then s!"o{y}" else cn.names.getD y "?"
    let addsT := nd.hist.filter (fun e => e.time == t)
    if !addsT.isEmpty then
      cn := { cn with
        exact := cn.exact.push s!"{nm x}@{nd.level}:{addsT.map (fun e => showVal nm e.val)}",
        lists := cn.lists.push s!"{nm x}@{nd.level}:{lv.map (fun q => (q.1, nm q.2))}",
        newKeys := cn.newKeys + (if P0.contains x then 0 else 1),
        oldChanged := if P0.contains x then cn.oldChanged.push x else cn.oldChanged }
    for (c, y) in lv do
      if !kn.leaf || segLen c == 7 then cn := canonWalk p P0 P t cn y
    return cn

def canonOf (p : Params) (P0 P : Nodes) (t : Time) : Canon :=
  match rootAt (viewN P) t with
  | none => {}
  | some r =>
    let cn := ({} : Canon).name P0 r
    canonWalk p P0 P t cn.1 r

/-! ## Reads and fill -/

def scanAll (p : Params) (P : Nodes) (t : Time) : List (Key × Nat) :=
  (scan p (viewN P) t {} 1000000000).map (fun kv => (kv.key, kv.h))

def refOp (r : Ref) (op : Tree.Op) : Ref :=
  match op with
  | .put k h => r.insert k h
  | .del k => r.erase k

structure Fill where
  nodes : Nat := 0
  klongs : Nat := 0
  live : Nat := 0
  dead : Nat := 0
  times : Nat := 0
  height : Nat := 0

def fillAt (p : Params) (P : Nodes) (t : Time) : Fill := Id.run do
  let v := viewN P
  match rootAt v t with
  | none => return {}
  | some r =>
    let mut a : Fill := {}
    for x in nodesAt p v t p.fuel r do
      match P[x]? with
      | some nd =>
        if !nd.isData && decide (nd.level ≤ p.keyMax) then
          let ks := klongsOf (nd.hist.upTo t)
          let n : KNode := { leaf := p.heightOf nd.level == 0, ks := ks }
          let times := ks.countP (fun k => match k with
            | .time _ => true
            | _ => false)
          a := { nodes := a.nodes + 1, klongs := a.klongs + ks.length,
                 live := a.live + (n.liveAt t).length, dead := a.dead + n.deadCount,
                 times := a.times + times, height := max a.height (p.heightOf nd.level) }
      | none => pure ()
    return a

/-! ## A transaction -/

def isPut : Tree.Op → Bool
  | .put _ _ => true
  | .del _ => false

def valBytes (ops : List Tree.Op) : Nat :=
  ops.foldl (fun s op => match op with
    | .put k _ => s + 40 + 8 * k.length
    | .del _ => s) 0

def opStr : Tree.Op → String
  | .put k _ => s!"put {k}"
  | .del k => s!"del {k}"

def runTx (cfg : Cfg) (name : String) (st : St) (T : Nat) (x : SIS.Check.Tree.TTx) : Except String St := do
  let p := cfg.p
  let ops := x.ops.toList.map (·.1)
  let keys := ops.map (·.key)
  let dups := keys.length - keys.eraseDups.length
  let P0 := st.P
  let w0 ← startW p P0 st.next
  let noops := ops.map (fun op => match op with
    | .del k => !st.ref.contains k
    | .put _ _ => false)
  let w ← match cfg.mode with
    | .today => do
      let (_, w) ← runAct p P0 T w0 (ops.mapM putKv)
      pure w
    | .pe => do
      let ((), w) ← runAct p P0 T w0 (Pe.runTx ops)
      pure w
    | .pet => do
      let ((), w) ← runAct p P0 T w0 (Pe.runTx ops { todayCut := ops.length == 1 })
      pure w
    | .peh => do
      let ((), w) ← runAct p P0 T w0 (Pe.runTx ops { cap := some (p.M / 2) })
      pure w
  match w.outside.find? (fun q => !w.taken.contains q.1) with
  | some (_, g, h) => throw s!"bounds: the tree leaves the level bounds: segment {g}, height {h}"
  | none => pure ()
  let c := changesOf T w
  let P' ← applyC P0 T c
  let b := bytesOf p P' c
  let mut stt := st.stats
  -- no node made is left out: every key node made is named by a live klong of
  -- a key node that the transaction changed or made, or is the new space root
  let named : Std.HashSet NodeId := b.changed.fold (fun acc z => match P'[z]? with
    | some nd =>
      let kn : KNode := { leaf := p.heightOf nd.level == 0, ks := klongsOf nd.hist }
      kn.live.foldl (fun acc q => acc.insert q.2) acc
    | none => acc) {}
  for z in b.made do
    if !named.contains z && !(w.newTop && w.top.rootKey == z) then
      stt := stt.fail "made.unnamed" s!"T {T}: key node {z} made and named by no live klong"
  stt := { stt with taken := stt.taken + w.taken.length, madeKey := stt.madeKey + b.madeKey,
                    tops := stt.tops + b.tops, versions := stt.versions + b.changed.size,
                    klongs := stt.klongs + b.klongs }
  for n in w.trail do
    stt := { stt with reached := bump stt.reached n }
  -- today's writer from the same P: the paired bytes, and cmp1
  if cfg.mode != .today && (cfg.paired || ops.length == 1) then
    match runAct p P0 T w0 (ops.mapM putKv) with
    | .error e => stt := stt.fail "today.error" s!"T {T}: {e}"
    | .ok (_, wt) =>
      let ct := changesOf T wt
      match applyC P0 T ct with
      | .error e => stt := stt.fail "today.error" s!"T {T}: {e}"
      | .ok Pt =>
        if cfg.paired then
          let bt := bytesOf p Pt ct
          stt := { stt with pTxs := stt.pTxs + 1, pRec := stt.pRec + bt.recB, pTop := stt.pTop + bt.top,
                            pNew := stt.pNew + bt.new, pAll := stt.pAll + bt.all,
                            pMadeKey := stt.pMadeKey + bt.madeKey, pKlongs := stt.pKlongs + bt.klongs }
        if ops.length == 1 then
          stt := { stt with tx1 := stt.tx1 + 1 }
          let ca := canonOf p P0 Pt T
          let cb := canonOf p P0 P' T
          let kind := if ca.exact == cb.exact then "exact"
            else if ca.lists == cb.lists then "lists"
            else if ca.newKeys == cb.newKeys && ca.oldChanged.toList.mergeSort (· ≤ ·) ==
                cb.oldChanged.toList.mergeSort (· ≤ ·) then "other.samenodes"
            else "other.othernodes"
          let isDel := match ops with
            | [.del _] => "del"
            | _ => "put"
          stt := { stt with cmp := bump (bump stt.cmp kind) s!"{kind}.{isDel}" }
          if kind != "exact" then
            let bt := bytesOf p Pt ct
            stt := { stt with cmp := bump (bump stt.cmp s!"{kind}.ktoday" bt.klongs) s!"{kind}.kpe" b.klongs }
            stt := { stt with cmp := bump (bump stt.cmp s!"{kind}.btoday" bt.all) s!"{kind}.bpe" b.all }
            -- a transaction of one operation where PE writes more than today
            if bt.all < b.all || bt.new < b.new || bt.klongs < b.klongs || bt.madeKey < b.madeKey then
              stt := { stt with cmp := bump stt.cmp "more" }
              if bt.all < b.all then stt := { stt with cmp := bump stt.cmp "more.ball" }
              if bt.new < b.new then stt := { stt with cmp := bump stt.cmp "more.bnew" }
              if bt.klongs < b.klongs then stt := { stt with cmp := bump stt.cmp "more.klongs" }
              if bt.madeKey < b.madeKey then stt := { stt with cmp := bump stt.cmp "more.made" }
              if stt.cmpLines.size < 40 then
                let notes := (wt.trail.reverse.filter (fun n => !n.startsWith "pe.")).eraseDups
                let pen := (w.trail.reverse.filter (fun n => n.startsWith "pe.")).eraseDups
                let line := s!"MORE {name} T={T} {kind} {opStr ops.head!} B-all today {bt.all} pe {b.all}; " ++
                  s!"B-new today {bt.new} pe {b.new}; klongs today {bt.klongs} pe {b.klongs}; " ++
                  s!"today-notes={notes} pe-notes={pen}\n  today: {ca.exact.toList}\n  pe:    {cb.exact.toList}"
                stt := { stt with cmpLines := stt.cmpLines.push line }
          if kind.startsWith "other" && stt.cmpLines.size < 20 then
            let notes := (wt.trail.reverse.filter (fun n => !n.startsWith "pe.")).eraseDups
            let line := s!"CMP1 {name} T={T} {kind} {opStr ops.head!} today-notes={notes}\n" ++
              s!"  today: {ca.lists.toList}\n  pe:    {cb.lists.toList}"
            stt := { stt with cmpLines := stt.cmpLines.push line }
  let delB := (ops.zip noops).foldl (fun s (op, noop) => match op with
    | .del k => if noop then s else s + 28 + 8 * k.length
    | .put _ _ => s) 0
  stt := { stt with txs := stt.txs + 1, ops := stt.ops + ops.length,
                    dels := stt.dels + (ops.filter (!isPut ·)).length,
                    noops := stt.noops + (noops.filter id).length, dupkeys := stt.dupkeys + dups,
                    bRec := stt.bRec + b.recB, bVal := stt.bVal + valBytes ops, bDel := stt.bDel + delB,
                    bTop := stt.bTop + b.top, changedT := stt.changedT + b.changed.size,
                    bNew := stt.bNew + b.new, bAll := stt.bAll + b.all }
  let st0 := st
  let mut st := { st with P := P', next := w.next, stats := stt }
  if cfg.contract then st := checkContract cfg st T ops c w
  if cfg.pec then st := pecCheck cfg name st0 st T ops
  stt := st.stats
  -- the reference and the map
  let ref := ops.foldl refOp st.ref
  for op in ops do
    stt := { stt with gets := stt.gets + 1 }
    let mv := get p (viewN P') T op.key
    if mv != ref.get? op.key then
      stt := stt.fail "map.get" s!"T {T}: get of {op.key}: the tree {mv}, the reference {ref.get? op.key}"
  for (jt, key, jv) in x.gets do
    stt := { stt with jreads := stt.jreads + 1 }
    let mv := get p (viewN P') jt key
    if mv != jv then stt := stt.fail "map.javaget" s!"T {T}: GET at {jt} of {key}: the tree {mv}, Java {jv}"
  for sc in x.scans do
    stt := { stt with jreads := stt.jreads + 1 }
    let ms := (scan p (viewN P') sc.t sc.req sc.limit).map (fun kv => (kv.key, kv.h))
    if ms != sc.results then stt := stt.fail "map.javascan" s!"T {T}: SCAN at {sc.t}"
  if cfg.contract then
    let cont := Contract.contents (st.heap.tree.at T)
    if cont != ref.toList then stt := stt.fail "C2.reference" s!"T {T}"
  return { st with ref := ref, stats := stt }

def showMap (m : Std.HashMap String Nat) : String :=
  ",".intercalate ((m.toList.mergeSort (fun a b => decide (a.1 ≤ b.1))).map (fun (k, v) => s!"{k}:{v}"))

def resultLine (name : String) (mode : Mode) (p : Params) (stt : Stats) : String :=
  s!"RESULT trace={name} mode={mode.name} M={p.M} G={p.G} H={p.H} m={p.mergeBelow} c={p.mergeMax} " ++
  s!"h={p.splitAbove} theta={p.theta} " ++
  s!"txs={stt.txs} ops={stt.ops} dels={stt.dels} noops={stt.noops} dupkeys={stt.dupkeys} tx1={stt.tx1} " ++
  s!"taken={stt.taken} madekey={stt.madeKey} tops={stt.tops} versions={stt.versions} " ++
  s!"klongs={stt.klongs} changedT={stt.changedT} brec={stt.bRec} bval={stt.bVal} bdel={stt.bDel} " ++
  s!"btop={stt.bTop} bnew={stt.bNew} ball={stt.bAll} " ++
  s!"ptxs={stt.pTxs} prec={stt.pRec} ptop={stt.pTop} pnew={stt.pNew} pall={stt.pAll} " ++
  s!"pmadekey={stt.pMadeKey} pklongs={stt.pKlongs} cmp={showMap stt.cmp} " ++
  s!"samples={stt.samples} snodes={stt.sNodes} " ++
  s!"sklongs={stt.sKlongs} slive={stt.sLive} sdead={stt.sDead} stimes={stt.sTimes} " ++
  s!"height={stt.height} endnodes={stt.endNodes} endklongs={stt.endKlongs} endlive={stt.endLive} " ++
  s!"enddead={stt.endDead} endtimes={stt.endTimes} gets={stt.gets} scans={stt.scans} " ++
  s!"jreads={stt.jreads} csteps={stt.cSteps} shapeend={showMap stt.shapeEnd} " ++
  s!"fails={showMap stt.fails} reached={showMap stt.reached}"

def addFill (stt : Stats) (f : Fill) : Stats :=
  { stt with samples := stt.samples + 1, sNodes := stt.sNodes + f.nodes,
             sKlongs := stt.sKlongs + f.klongs, sLive := stt.sLive + f.live,
             sDead := stt.sDead + f.dead, sTimes := stt.sTimes + f.times,
             height := max stt.height f.height }

/-! ## 030-21: the new writer alone, `--pecrun` -/

/-- The standalone run's state: the new writer's heap, top and next id, the
reference, and the counts. -/
structure PR where
  heap : Contract.Heap
  tp : Contract.Top
  next : NodeId
  ref : Ref := ∅
  snaps : Array (Nat × Ref) := #[]
  txs : Nat := 0
  ops : Nat := 0
  refused : Nat := 0
  refusedBy : Std.HashMap String Nat := {}
  madeKey : Nat := 0
  versions : Nat := 0
  tops : Nat := 0
  bNew : Nat := 0
  bAll : Nat := 0
  bTop : Nat := 0
  wsDup : Nat := 0
  gets : Nat := 0
  jreads : Nat := 0
  height : Nat := 0
  fails : Std.HashMap String Nat := {}
  first : Array String := #[]

def PR.fail (r : PR) (check msg : String) : PR :=
  { r with fails := bump r.fails check,
           first := if r.first.size < 6 then r.first.push s!"{check}: {msg}" else r.first }

def scanReqOf (q : SIS.Tree.ScanReq) : Contract.ScanReq :=
  { start := q.start, inclusive := q.inclusive, forward := q.forward, endKey := q.endKey,
    endInclusive := q.endInclusive }

/-- The trial's start as runTrace builds it: the contract heap of the
primordial structure (the root left out, the top node not a key node) and
its top. -/
def trialStart (p : Params) : Contract.Heap × Contract.Top :=
  let P := toNodes (initStruct p)
  let objs : Std.HashMap NodeId Contract.Obj := P.fold (fun m x nd => match objOf p nd with
    | some o => if x == root then m else m.insert x o
    | none => m) {}
  ({ objs := objs, roots := [(0, 1)] }, [(2, (⟨0, 1, []⟩ : Contract.TopNode))])

/-- The new writer's start: PeWriter's `startTree`, `startTop` and `startNext`
if they are the trial's start (node 1 the only node of startTree among the ids
below 1000 and the trial heap's only node, the same space roots and top);
else the trial's start with its first id, 1000. -/
def pecStart (p : Params) (cf : Contract.PE.Cfg) : String × Contract.Heap × Contract.Top × NodeId :=
  let (h, tp) := trialStart p
  let s := Contract.PE.startTree cf
  let same := h.objs.size == 1 && h.objs[1]? == s.obj 1 && s.roots == h.roots &&
    Contract.PE.startTop == tp && (List.range 1000).all (fun x => x == 1 || (s.obj x).isNone)
  match same, s.obj 1 with
  | true, some o1 =>
    ("startTree", { objs := ({} : Std.HashMap NodeId Contract.Obj).insert 1 o1, roots := s.roots },
      Contract.PE.startTop, Contract.PE.startNext)
  | _, _ => ("trial", h, tp, 1000)

/-- One transaction of the standalone run at time T; false if peTx refused it. -/
def pecStep (cf : Contract.PE.Cfg) (p : Params) (r0 : PR) (T : Nat) (x : SIS.Check.Tree.TTx) :
    PR × Bool := Id.run do
  let ops := x.ops.toList.map (·.1)
  let cops := ops.map opOf
  let mut r := r0
  let mut out := Contract.PE.peTx cf T r0.heap.tree r0.tp r0.next cops
  if out.isNone then
    let why := refusalOf cf cops
    r := { r with refused := r.refused + 1, refusedBy := bump r.refusedBy why }
    if r.first.size < 6 then r := { r with first := r.first.push s!"refused ({why}): T {T}" }
    -- a refusal for `longdel` only: run again without those deletes (noops)
    if why == "longdel" then
      out := Contract.PE.peTx cf T r0.heap.tree r0.tp r0.next (dropLong cf cops)
      if out.isNone then r := { r with refusedBy := bump r.refusedBy "longdel.again" }
  match out with
  | none => return (r, false)
  | some o =>
    let h0 := r0.heap
    let h' := applyOut h0 o
    let s' := h'.tree
    let sT := s'.at T
    let D : Std.HashSet NodeId := Std.HashSet.ofList o.D
    let dups := wsDups o.ws
    if dups > 0 then
      r := { r with wsDup := r.wsDup + dups }
      r := r.fail "wsdup" s!"T {T}: {dups}"
    -- the frame as checkContract computes it, over the nodes written; the
    -- space roots extended; fresh ids
    let mut frameOk := Contract.rootsExt T h0.roots h'.roots
    let mut freshOk := true
    let mut made := 0
    let mut versions := 0
    let mut bnew := 0
    let mut ball := 0
    for (y, ob) in o.ws do
      let isOld := h0.objs.contains y
      match h0.objs[y]? with
      | some o0 => if !(Contract.extOk T o0 ob && D.contains y) then frameOk := false
      | none =>
        match ob with
        | .key _ => if !D.contains y then frameOk := false
        | .val _ => pure ()
        if y < r0.next || o.next ≤ y then freshOk := false
      match ob with
      | .key n =>
        let b := 32 + 16 * n.ks.length
        versions := versions + 1
        ball := ball + b
        if !isOld then
          made := made + 1
          bnew := bnew + b
      | .val _ => pure ()
    let mut tops := 0
    let mut btop := 0
    for (z, n) in o.top.drop r0.tp.length do
      tops := tops + 1
      btop := btop + 48 + 16 * n.skips.length
      if z < r0.next || o.next ≤ z || h'.objs.contains z then freshOk := false
    if !frameOk then r := r.fail "C3.frame" s!"T {T}"
    if !freshOk then r := r.fail "ids.fresh" s!"T {T}"
    let cp : Contract.Params := { M := p.M }
    if !Contract.contractOk cp T h0.tree cops s' then
      if !Contract.invOk cp sT then r := r.fail "C1.inv" s!"T {T}"
      else r := r.fail "C2.contents" s!"T {T}"
    if !Contract.treeOkB sT then r := r.fail "C4.tree" s!"T {T}"
    if !(Contract.topStepB T r0.tp o.top && h'.roots == Contract.rootsOf o.top) then
      r := r.fail "C5.top" s!"T {T}"
    let q : Contract.ShapeParams := ⟨p.H, p.mergeBelow, p.theta⟩
    for f in (Contract.shapeFaults q sT).eraseDups do
      r := r.fail s!"shape.{f}" s!"T {T}"
    let ref := ops.foldl refOp r0.ref
    if Contract.contents sT != ref.toList then r := r.fail "C2.reference" s!"T {T}"
    let mut gets := 0
    for op in ops do
      gets := gets + 1
      if Contract.get sT op.key != ref.get? op.key then
        r := r.fail "map.get" s!"T {T}: get of {op.key}"
    let mut jreads := 0
    for (jt, key, jv) in x.gets do
      jreads := jreads + 1
      if Contract.get (s'.at jt) key != jv then
        r := r.fail "map.javaget" s!"T {T}: GET at {jt} of {key}"
    for sc in x.scans do
      jreads := jreads + 1
      if Contract.scan (s'.at sc.t) (scanReqOf sc.req) sc.limit != sc.results then
        r := r.fail "map.javascan" s!"T {T}: SCAN at {sc.t}"
    let ht := match sT.root.bind sT.obj with
      | some (.key n) => cf.htOf n.level
      | _ => 0
    r := { r with heap := h', tp := o.top, next := o.next, ref := ref,
                  txs := r.txs + 1, ops := r.ops + ops.length, madeKey := r.madeKey + made,
                  versions := r.versions + versions, tops := r.tops + tops, bNew := r.bNew + bnew,
                  bAll := r.bAll + ball, bTop := r.bTop + btop, gets := r.gets + gets,
                  jreads := r.jreads + jreads, height := max r.height ht }
    return (r, true)

/-- The standalone run of a trace. -/
def runPecTrace (p : Params) (name : String) (tt : SIS.Check.Tree.TTrace) : IO Bool := do
  let cf := peCfg p
  let (start, h, tp, next) := pecStart p cf
  IO.println s!"PECSTART trace={name} start={start} next={next}"
  let mut r : PR := { heap := h, tp := tp, next := next, snaps := #[(0, ∅)] }
  for x in tt.txs do
    if x.idx == 0 then continue
    let T := x.idx
    let (r', ok) := pecStep cf p r T x
    r := r'
    if !ok then break
    if r.txs % 50 == 0 then r := { r with snaps := r.snaps.push (T, r.ref) }
  for (T, ref) in r.snaps do
    if T == 0 then continue
    if Contract.contents (r.heap.tree.at T) != ref.toList then r := r.fail "map.history" s!"T {T}"
  IO.println (s!"PECRUN trace={name} M={p.M} G={p.G} H={p.H} m={p.mergeBelow} c={p.mergeMax} " ++
    s!"h={p.splitAbove} theta={p.theta} start={start} txs={r.txs} ops={r.ops} refused={r.refused} " ++
    s!"refusedby={showMap r.refusedBy} " ++
    s!"madekey={r.madeKey} versions={r.versions} tops={r.tops} bnew={r.bNew} ball={r.bAll} " ++
    s!"btop={r.bTop} maxheight={r.height} gets={r.gets} jreads={r.jreads} wsdup={r.wsDup} " ++
    s!"fails={showMap r.fails}")
  for f in r.first do
    IO.println s!"  {f}"
  return r.fails.isEmpty && r.refused == 0

def runTrace (mode : Mode) (contract paired pec pecrun : Bool) (dump : Option Nat) (hplus : Nat)
    (file : String) : IO Bool := do
  let text ← IO.FS.readFile file
  let tt := SIS.Check.Tree.parseTree text
  let name := (file.splitOn "/").getLast!
  match tt.tree with
  | none =>
    IO.println s!"RESULT trace={name} mode={mode.name} fails=noTREEline"
    return false
  | some (p0, _) =>
    let p := { p0 with H := p0.H + hplus }
    if pecrun then return (← runPecTrace p name tt)
    let cfg : Cfg :=
      { mode := mode, p := p, contract := contract || pec, paired := paired, pec := pec, dump := dump }
    let P := toNodes (initStruct p)
    let objs : Std.HashMap NodeId Contract.Obj := P.fold (fun m x nd => match objOf p nd with
      | some o => if x == root then m else m.insert x o
      | none => m) {}
    let mut st : St := { P := P, heap := { objs := objs, roots := [(0, 1)] },
                         tp := [(2, (⟨0, 1, []⟩ : Contract.TopNode))],
                         snaps := #[(0, ∅)] }
    let mut lastT := 0
    let mut n := 0
    for x in tt.txs do
      if x.idx == 0 then continue
      let T := x.idx
      match runTx cfg name st T x with
      | .error e =>
        st := { st with stats := st.stats.fail "error" s!"T {T}: {e}" }
        break
      | .ok st' =>
        st := st'
        lastT := T
        n := n + 1
        if n % 10 == 0 then
          let mut stt := { st.stats with scans := st.stats.scans + 1 }
          if scanAll p st.P T != st.ref.toList then stt := stt.fail "map.scan" s!"T {T}"
          st := { st with stats := stt }
        if n % 20 == 0 then st := { st with stats := addFill st.stats (fillAt p st.P T) }
        if n % 50 == 0 then st := { st with snaps := st.snaps.push (T, st.ref) }
    let t := lastT
    let mut stt := { st.stats with scans := st.stats.scans + 1 }
    if scanAll p st.P t != st.ref.toList then stt := stt.fail "map.scan" s!"T {lastT}"
    let f := fillAt p st.P t
    stt := addFill stt f
    stt := { stt with endNodes := f.nodes, endKlongs := f.klongs, endLive := f.live,
                      endDead := f.dead, endTimes := f.times }
    for (T, r) in st.snaps do
      if T == 0 then continue
      stt := { stt with scans := stt.scans + 1 }
      if scanAll p st.P T != r.toList then stt := stt.fail "map.history" s!"T {T}"
    IO.println (resultLine name mode p stt)
    for f in stt.first do
      IO.println s!"  {f}"
    for l in stt.cmpLines do
      IO.println l
    if pec then
      IO.println (s!"PEC trace={name} txs={stt.txs} same={stt.pecSame} differ={stt.pecDiffer} " ++
        s!"refused={stt.pecRefused} refusedby={showMap stt.pecRefusedBy} fsame={stt.pecFSame} " ++
        s!"fdiffer={stt.pecFDiffer} frefused={stt.pecFRefused} wsdup={stt.pecWsDup} nodes={stt.pecNodes}")
      for l in stt.pecLines do
        IO.println l
    return stt.fails.isEmpty && (!pec || (stt.pecDiffer == 0 && stt.pecRefused == 0 && stt.pecWsDup == 0))

end PeTrial

open PeTrial in
def main (args : List String) : IO UInt32 := do
  match args with
  | m :: rest =>
    match Mode.ofString m with
    | none =>
      IO.println "Usage: petrial today|pe|pet|peh [--contract] [--paired] [--pec] [--pecrun] [--hplus=K] TRACE..."
      return 2
    | some mode =>
      let contract := rest.contains "--contract"
      let paired := rest.contains "--paired"
      let pec := rest.contains "--pec"
      let pecrun := rest.contains "--pecrun"
      let dump := rest.foldl (fun k o => if o.startsWith "--pecdump=" then (o.drop 10).toNat? else k) none
      let hplus := rest.foldl (fun k o => if o.startsWith "--hplus=" then ((o.drop 8).toNat?).getD k else k) 2
      let files := rest.filter (fun o => !o.startsWith "--")
      let mut ok := true
      for f in files do
        let r ← runTrace mode contract paired pec pecrun dump hplus f
        ok := ok && r
      IO.println (if ok then "PETRIAL OK" else "PETRIAL FAILED")
      return (if ok then 0 else 1)
  | [] =>
    IO.println "Usage: petrial today|pe|pet|peh [--contract] [--paired] [--pec] [--pecrun] [--hplus=K] TRACE..."
    return 2
