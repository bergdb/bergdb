Contributing to BergDB
======================

BergDB is written and owned by Frans Lundberg. For now it does not take
code from others: Frans writes the code. Reports and ideas are welcome.

TO CHECK (Frans): the policy. This draft is option A, no code from
others. The other two options, for later: a contributor licence
agreement, or an assignment of the copyright, each read by a lawyer
first.


What is welcome
---------------

* **Bug reports.** Open an issue. Say which release or commit, which JDK
  and which operating system; what you did, what you expected and what
  happened. A short program that shows the bug helps most.
* **Ideas and questions.** Open an issue.
* **Errors in the documentation.** Open an issue that names the file and
  the section.

TO CHECK (Frans): issues on or off, and GitHub Discussions on or off. If
Discussions is on, ideas and questions go there.

To report a vulnerability, do not open an issue: see
[SECURITY.md](SECURITY.md).


What is not accepted
--------------------

* **Pull requests.** A pull request is closed without being merged, even
  a small one. If it shows a bug, the bug is fixed by Frans.
* **Patches**, in an issue or elsewhere. Describe the change in words.
  A few lines of code that show a bug are fine.

This may change. If BergDB takes code from others later, each
contributor will first sign an agreement, and this file will say which.
