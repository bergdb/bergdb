This packages implements the core data structure which is a graph in the graph theory sense. More specifically, it is a DAG (directed acyclic graph). This is the in-memory data structure used by the database. This is a low-level package. Lower-lever than bergdb.core (core uses this package and this package is not allowed to use code).

Scope: traverse the graph (DAG), support get / getMany / putKv operations. Testable (without Db).

Anti-scope: db clock, locking, STM, statistics.

Inject what is needed and work with call-backs and the like. This package has does not depend on core.

Allowed package dependencies: common, nanotest, possibly stream, possibly storage.

This package is testable in isolation. That is, without higher-level packages: bergdb.pubimp, bergdb.core.
