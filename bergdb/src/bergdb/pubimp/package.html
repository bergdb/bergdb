This package implements the public BergDB API. It is not directly visible to the Pub user, but it implements the interfaces defined in bergdb.pub.

Depends on: pub, core, stream, common, nanotest. Note that we allow the circular package dependency: pubimp -> pub -> pubimp.

======== DEV NOTES ========

Developers' notes for this package and for pub package.

Layer Pub, should not have public constants that can be inlined 
(static final variable initialized to constant expression).
Ref: Video "Effective Java - Still Effective After All These Years", http://www.youtube.com/watch?v=V1vQf4qyMXg&feature=related
Can be an issue when client code compiled against Version 1 of a library, and run against
Version 2 of the library. Client code will have the inlined constants from Version 1, but run other
code from Version 2 of the library.
