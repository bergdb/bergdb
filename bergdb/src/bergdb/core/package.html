With support from other packages, this package implements the Core Layer. The Db class is the main class of the package.

Depends on: common, nanotest, stream, storage.

For BergDB developers

Stream Format

See stream-format.txt for documentation of the stream format in general and its versioning in particular.

Exceptions

Methods in DB class should have documented exceptions for illegal parameter values. [throw new IllegalArgumentException...]. More "internal" methods, private, package private, or those never expected to be called by a Core Layer user, may have more lax parameter checking. Or use assertions, or throw Error/Bug when parameters are illegal. The input is expected to be correct for these methods.
