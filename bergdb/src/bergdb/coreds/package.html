This packages implements the CoreDs - the core data structure. This is the in-memory data structure used by the database. This is a low-level package. Lower-lever than bergdb.core (core uses this package).

Scope: traverse the graph (DAG), support get / getMany / setKv operations. Testable (without Db).

Anti-scope: db clock, locking, STM, stats?

Inject what is needed and work with call-backs and the like. This package has does not depend on core. Mock stream if needed.

Allowed package dependencies: common, nanotest, possibly stream, possibly storage, not core.


We would like this package to be testable in isolation. That is, without Db and the rest
of the core package.
