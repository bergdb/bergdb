This package is the implementation of Nanotest -- a very small, and powerful test framework.

Depends on: nothing. The package is self-contained, only depends on Java 1.5.

Properties of Nanotest

* Suitable for post-deploy self-testing.
* Small.
* Code to be tested need not be dependent on Nanotest. Just use convention "public static void testXxx()".
* Supports unit tests, longer-running functional tests and also performance tests.
* Test are easy to group. For example into "unit", "functional", 
  "perf". Testing is started by selecting a set of test groups to run and a set of classes/methods.
* Tests can report arbitrary key-value pairs to the test runner while the test is running.
* A test is successful if it does not throw an exception.
* Deterministic thread testing supported.
* Suitable for being embedded in created software.

---- Dependencies ----
None allowed. This package should be self-contained.
