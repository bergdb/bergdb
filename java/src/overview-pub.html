The Pub API is a small, but powerful API that should make it easy for you to store data. The goal is to keep things simple so that you can focus on your specific application rather than on struggling with database issues. BergDB is a database library, it is used in-process together with your application code.

The API is the packages bergdb.pub and bergdb.pub.util, and the Core's bergdb.core.Db with the types of its signatures. Everything else, bergdb.pubimp included, is not API, whatever is public in it, and may change in any release (bergdb 020-10, section 7). java/build.sh makes build/bergdb-release.jar, the jar a release ships: the classes of src only.

Values are Strings, byte[]s and Java objects of Data Object classes. User indexes (Database.indexBuilder(), Connection.useIndex()) list the objects of a directory in the order of their fields, and the primary scan (Connection.usePrimary()) a directory's values in the order of their keys; see IndexBuilder, UseIndexBuilder and UsePrimaryBuilder.

Every string that BergDB stores, a key, a String value and each string in an object, is Unicode text stored as well-formed UTF-8; a String with a lone surrogate is refused. The rule in full: Strings, in the package bergdb.pub.

An object that is neither a String nor a byte[] is a Data Object: a public class with a public no-argument constructor and public fields of types on a closed list. A put stores it exactly, leaving a null field out (BergDB stores no null) and refusing a null array element; a get converts each stored field to its field's type, best effort. In full: Objects and Null and absent fields, in the package bergdb.pub.

// Example code:
// A complete program to put/get/delete a string under the name (key) "/a".

package bergdb.demo;

import bergdb.pub.Connection;
import bergdb.pub.Database;
import bergdb.pub.Factory;

class Demo {
    private static void put() {
        try (Database database = Factory.database().create("db-demo").start()) {
            Connection c = database.connection();
            c.put("/a", "value");
            c.sync();
        }
    }
    
    private static void get() {
        try (Database database = Factory.database().open("db-demo").start()) {
            System.out.println(database.connection().get("/a", String.class));
        }
    }

    private static void delete() {
        try (Database database = Factory.database().open("db-demo").start()) {
            Connection c = database.connection();
            c.delete("/a");
            c.sync();
        }
    }
    
    public static void main(String[] args) {
        if (args.length == 0) {
            System.out.println("Use one of: put, get, delete.");
            return;
        }
        
        if (args[0].equals("put")) {
            put();
        } else if (args[0].equals("get")) {
            get();
        } else if (args[0].equals("delete")) {
            delete();
        } else {
            System.out.println("Bad command.");
        }
    }
}
