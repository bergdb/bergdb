BergDB is a database library for Java: it runs in-process, together with your application code, and keeps its data in a directory, or in memory. You put values at keys, such as "/a.txt", and get them back. The Pub API is small, but powerful: it should make it easy for you to store data, so that you can focus on your application rather than on database issues.

A first program

This complete program keeps the text "Hello world!" in a database in the directory db-demo. Run it with put, then get, then delete:

// A complete program to put/get/delete a string at the key "/a.txt".

import bergdb.pub.Connection;
import bergdb.pub.Database;
import bergdb.pub.Factory;

class Demo {
    private static void put() {
        try (Database database = Factory.database().create("db-demo").start()) {
            Connection c = database.connection();
            c.put("/a.txt", "Hello world!");
            c.sync();
        }
    }

    private static void get() {
        try (Database database = Factory.database().open("db-demo").start()) {
            System.out.println(database.connection().get("/a.txt", String.class));
        }
    }

    private static void delete() {
        try (Database database = Factory.database().open("db-demo").start()) {
            Connection c = database.connection();
            c.delete("/a.txt");
            c.sync();
        }
    }

    public static void main(String[] args) {
        if (args.length == 0) {
            System.out.println("Use one of: put, get, delete.");
            return;
        }

        if (args[0].equals("put")) {
            put();
        } else if (args[0].equals("get")) {
            get();
        } else if (args[0].equals("delete")) {
            delete();
        } else {
            System.out.println("Bad command.");
        }
    }
}

Java 17 or later runs the file as it is, with BergDB's jar (here bergdb.jar) on the class path:

$ java -cp bergdb.jar Demo.java put
$ java -cp bergdb.jar Demo.java get
Hello world!
$ java -cp bergdb.jar Demo.java delete
$ java -cp bergdb.jar Demo.java get
null

create() opens the database in the directory, or creates one there; open() only opens one that exists. A get of a key without a value gives null. The try block closes the database when the block ends: close, or stop, every database that you start.

Next

The package bergdb.pub goes on from here, with a short example of each main use: text and bytes, objects, transactions, earlier states, the keys of a directory in order, and indexes. The rules in full come after the examples.

The API is the packages bergdb.pub and bergdb.pub.util, and the Core's bergdb.core.Db; a release ships them in one jar (The API and its jar, in the package bergdb.pub).
