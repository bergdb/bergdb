This is the full Javadoc of all BergDB classes, focus on using the smaller Pub API (package bergdb.pub) if that is enough for you.

BergDB developers (those who wish to modify the BergDB library) should start by reading the docs for package bergdb.dev.

The API formed by all classes of BergDB is certainly *not* expected to be stable between BergDB versions and releases. Stick to using the Pub API for better stability between releases.

With that said, there are useful features that are not available from Pub and for highest possible performance, use the class bergdb.core.Db directly. The test source code in bergdb.core.DbTester could be of interest if you like to know how to use Db directly.

The class bergdb.pub.DbObject can also be of interest - a stored object, read and written in BergDB's object format (format 2); Data Objects are converted to and from it.
