This packages implements the main in-memory data structures. It is a DAG (directed acyclic graph), implemented in class Dag and the TransSeq sequence of transaction information. This is the in-memory data structures used by the database. This is a low-level package. Lower-level than bergdb.core. Package bergdb.core uses this package, but this package is not allowed to use core.

Scope: graph (DAG) traversal, support get / getMany / putKv operations. Testable (without bergdb.core).

Anti-scope: db clock, locking, STM, statistics.

Inject what is needed and work with callbacks. This package does not depend on core; this package is testable in isolation. That is, it is tesable without higher-level packages such as bergdb.core and bergdb.pubimp.

Dependencies: common, nanotest, pub.util (not: core, stream, storage).
