This package is the implementation of Nanotest -- a very small and still powerful test framework.

Depends on: nothing. The package is self-contained, only depends on JVM (5 or later).

Properties of Nanotest
======================

* Small and simple.
* Suitable for post-deploy self-testing.
* Code to be tested need not be dependent on Nanotest. Just use convention "static void testXxx()".
* Suitable for unit tests, longer-running functional tests and also performance tests.
* Test are easy to group. For example into "unit", "functional", 
  "perf". Testing is started by selecting a set of test groups to run and a set of classes/methods.
* Testing with files supported. Files are automatically removed at end of test.
* A test is successful if it does not throw an exception.
* Suitable for being embedded in created software.
  End users can run test suit to ensure working software on their particular 
  platform / JVM.

Usage: create tests
===================

To create a Nanotest do either one of:

1. Create a static void method with a name that starts with "test". 
   Example: [public static void testMe()].
2. Create a static void method annotated with the Nano annotation. 
   Example: [@Nano public static myTestMethod()].

The first alternative is allowed to create tests that are completely independent of
the Nanotest library. Any test run library could be used to run the tests.
The second alternative is good when one want to group tests together.
For example: [@Nano("unit perf") public static void t2()] defines a test that belongs
to groups "unit" and "perf". By default, tests belong to the "unit" group.

Test methods either take no argument, or one argument of type 


Usage: run tests
================

Use the TestRunner class. The BergDB software (bergdb.dev.NanotestForBergDB) can be
used as a template.
