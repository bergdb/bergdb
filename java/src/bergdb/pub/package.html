Together with pub.util, this package forms the public BergDB API, "Pub". The package is used to store String and byte[] values by key, and Java objects, experimental in 2026.3.

Experimental in 2026.3, with known faults: a value that is neither a String nor a byte[] (put(Object), a put of an object at a key, a get into another class), and the user indexes (Database.indexBuilder() and deleteIndex(), Connection.useIndex() and usePrimary(), and the interfaces IndexBuilder, UseIndexBuilder and UsePrimaryBuilder; Database.PRIMARY, StartupInfo.getStartupJobs(), and the exceptions of these parts). They may change in a later release (bergdb 018-01, D6). The rest of the Pub API, with the puts, gets and deletes of String and byte[] values, is not experimental.

Depends on: common, nanotest, pub.util, pubimp. Only test code (the @Nano methods) uses nanotest. Factory uses pubimp to create a DatabaseBuilder: the circular package dependency pub -> pubimp -> pub is by design. Time also uses pubimp's TimeResolver.
